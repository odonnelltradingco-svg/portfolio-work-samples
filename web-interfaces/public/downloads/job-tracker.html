What changed

A consistent working view

Known status aliases and outside whitespace are normalized. Active jobs include the client, next action and a sortable due date.

Duplicates remain traceable

Two later copies match every normalized field and a shared identity. They move to Archive with a reference to the retained record.

Uncertainty stays visible

An unknown status, a missing job identity and a conflicting pair stay in Review. A posting’s age alone does not close it.

What the client receives

  • Five sheets: Overview, Active, Archive, Review and Original.
  • Status dropdowns, table filters and frozen headers.
  • A formula-driven record reconciliation and status count.
  • A changeable reference date for due follow-ups.
  • Source-record IDs and a reason for every archived or review entry.
  • The source CSV, Python cleaner, decision log and expected outputs.

The cleaned workbook is a snapshot. Update it manually or rerun the CSV cleaner for a fresh source; the script produces CSV and JSON files.

A summary that reconciles

Every source record has one destination. The reference date starts at September 6, 2026, when three of the active follow-ups are due. Undated follow-ups are excluded from that count.

The workbook includes the rules and maintenance notes alongside its totals.

How I checked it

  • Six Python tests cover record conservation, source preservation, duplicate conflicts, date validation, URL identity and formula-like CSV text.
  • The final ZIP package was extracted and rerun. All four output files matched the included expected files exactly.
  • Workbook totals, status counts and follow-up dates were checked, including a changed date and an extra-record mismatch.
  • All five sheets were rendered and inspected. The saved file contains numeric dates, four tables, frozen panes and status validation.

Clear boundaries

This sample does not access live job postings, merge records by fuzzy title matching or silently discard uncertain entries. The client’s format, row count and archive rules should be agreed before a real cleanup.

Summary formulas and validation cover rows 7–206. They can be extended for a larger tracker. The workbook has no macros, external workbook links or automatic import service.

Python 3.10+; no extra packages. Workbook previews were checked locally, without claiming compatibility tests in every Excel version or a client’s environment.
